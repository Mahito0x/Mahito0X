## About Me

I'm a developer who enjoys building things from scratch, breaking them, fixing them, and occasionally wondering why I even started.

* **Building:** I run [Lumière Labs](https://lumierelabs.xyz) where I create tools and infrastructure for Discord communities.
* **Daraja SDK:** I am working on the [Daraja SDK](https://daraja.lumierelabs.xyz), which is a TypeScript SDK for [Safaricom's Daraja API](https://developer.safaricom.co.ke/). My main focus here is making the developer experience much less painful.
* **Exploring:** I dive into full-stack development, APIs, backend architecture, infrastructure, and developer tooling.
* **Learning:** I spend my time mastering TypeScript, Python, Linux, and all the tiny details that somehow add up to *backend engineering.*
* **Interested In:** I love open source, clean interfaces, useful abstractions, and software that actually makes sense without needing a 40-page manual.
* **Outside Code:** You will find me enjoying nature, admiring good design, and probably starting yet another project before finishing my last one.

> **Currently:** I am building, learning, and experimenting while trying really hard not to turn every random idea into a brand new GitHub repository.
